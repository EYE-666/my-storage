# 我的起始页

这是我学习 HTML 和 CSS 时做的一个小项目。

平时打开常用网站时，总要重复输入网址，所以我想做一个简单的个人导航页。现在页面里放了学在西电、西电一站式服务大厅、Google 翻译、GitHub、ChatGPT 和虎牙直播，点击卡片就可以直接打开对应网站。

## 项目功能

- 使用纯 HTML 和 CSS 编写，没有使用框架
- 常用网站以卡片形式排列
- 支持电脑和手机页面
- 点击链接时会在新标签页打开
- 可以直接作为浏览器的本地启动页使用

## 使用方法

1. 下载这个项目。
2. 双击打开 `index.html`。
3. 也可以把这个文件的本地地址设置成浏览器启动页。

## 项目结构

```text
my-startpage/
├── index.html
└── README.md
```

## 开发想法

目前这个项目比较简单，主要是练习网页布局、配色和响应式设计。以后如果继续学习 JavaScript，我想尝试加入自定义网站、搜索框或者主题切换等功能。

这是我的前端入门小作品，还有很多可以改进的地方，欢迎提出建议。
